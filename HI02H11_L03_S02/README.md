# HI02H11_L03_S02 — लड़का या लड़की? — लिंग पहचानो

**Grade:** G2 · **LO:** HI02H11_L03 · **Attribute:** H11 · **Type:** CORE

> लिंग-सूचक शब्द-रूप बदलाव को पहचानता है — जैसे लड़का से लड़की, शेर से शेरनी।

**Slides:** 18 · Tutorial 4 / Guided 4 / Independent 4 / Practice 2 / Mastery 4

## Teach-then-test — mini-games
- **GENDER_INTRO / MEET_GENDER** (teach) — meet पुल्लिंग vs स्त्रीलिंग; model लड़का→लड़की (आ→ई) and शेर→शेरनी (नी).
- **TAP_GENDER** (pick) — see a picture, tap its लिंग.
- **TAP_PICTURE_BY_GENDER** (pick) — see a लिंग, tap the matching picture.
- **SORT_GENDER** (produce) — drag each word into its पुल्लिंग / स्त्रीलिंग bin.
- **MATCH_GENDER_PAIRS** (produce) — drag each पुल्लिंग word onto its स्त्रीलिंग pair (लिंग-रूप मिलान).
