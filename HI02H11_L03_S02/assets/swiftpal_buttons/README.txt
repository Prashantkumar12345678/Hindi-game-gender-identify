SwiftPAL buttons - HI02H11_L01_S01
=================================

Open index.html to see them all.

  btn-play.svg           Play               186 x 64     Cover screen. Starts the lesson.
  btn-play-waiting.svg   Play - waiting     186 x 64     Same button while the voice-over runs. Not tappable.
  btn-next.svg           Next               170 x 62     Bottom of every teaching page, once the page is answered.
  btn-next-disabled.svg  Next - disabled    170 x 62     The same pill before the page is answered.
  btn-finish.svg         Finish             135 x 89     Celebration page. Leaves the lesson.
  btn-hint.svg           Hint               68 x 68      Appears after a wrong answer.
  btn-audio.svg          Audio / listen     62 x 60      Replays the current line. On the cover and every page header.

Notes
-----
* Self-contained SVG: no fonts, no external files, no CSS needed.
* Each file is padded 14px on every side so the drop shadow is not clipped;
  the button box starts 14px in from the edge.
* Arrows and the play triangle are vector paths, not text characters.
* Colours: gold #FCB717, navy #0B3D8C, disabled #EDEDED fill / #C2C2C2 ink,
  hint gradient #1987FC -> #1565F4, rim #FFFFFF.
* The hint bulb and the audio chip are lifted from the game unchanged.
  The four pill buttons are redrawn from the game's CSS.
