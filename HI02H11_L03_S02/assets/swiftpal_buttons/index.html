SwiftPAL buttons

Every button used in HI02H11_L01_S01, as standalone SVG. Each file is self-contained — no fonts, no external references, no CSS — so it can be dropped straight into another game.

Using them

<!-- as an image -->
<img src="btn-next.svg" alt="Next">

<!-- as a real button -->
<button class="btn"><img src="btn-next.svg" alt="Next"></button>
<style>
  .btn{ background:none; border:0; padding:0; cursor:pointer; }
  .btn:active{ transform:translateY(3px); }   /* the press the original has */
</style>
  • Each file is padded by 14px on every side so its drop shadow is not clipped. The button box therefore starts 14px in from the edge — allow for that when aligning.
  • The arrows and the play triangle are paths, not text, so they look identical everywhere without shipping a font.
  • Scale them freely; they are vector. The sizes listed are the ones used in the game.
